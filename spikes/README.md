# Spikes de la Fase 0

Código desechable para responder las 3 preguntas de riesgo. Veredictos en `docs/spikes/`.

- `s01-audio-ios/` — banco de pruebas de audio en background para iPhone (publicado como artifact; regenerable con `generar.sh`)
- `s02-extraction/` — comparativa de extractores PDF sobre corpus público (`run_compare.py`)
- `s03-tts/` — kit de prueba ciega de voces TTS (`generar_muestras.py`, requiere API keys del autor)
